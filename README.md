# 🏥 Healthcare Platform — Doctor Availability & Teleconsultation

A full-stack healthcare web application designed to make remote healthcare access more convenient by helping patients discover doctors, check availability, book appointments, and communicate with doctors online.

The platform combines appointment management, real-time messaging, video consultations, and a chatbot assistant in a unified web experience.

## ✨ Features

### 🩺 Doctor Listing & Availability
- Browse available doctors.
- View doctor availability and status-based interactions.
- Find doctors through a centralized interface.

### 📅 Appointment Management
- Book consultations with doctors.
- Support the patient-to-doctor appointment workflow.

### 💬 Real-Time Chat
- Socket-based messaging between patients and doctors.
- Room-based communication sessions.
- Real-time message exchange using Socket.IO.

### 📹 Video Consultation
- Peer-to-peer video communication using WebRTC.
- Room-based connection setup for remote consultations.
- Enables face-to-face interaction without requiring an in-person visit.

### 🤖 Chatbot Assistant
- Floating chatbot interface on the homepage.
- Provides quick guidance and helps users navigate the platform.

### 👥 Role-Based User Experience
- Separate workflows for patients and doctors.
- Interfaces designed around the needs of each user role.

## 🏗️ Application Overview

The platform brings together several components to support remote consultations:

1. **Frontend:** Provides interfaces for patients and doctors.
2. **Backend:** Handles server-side application logic and requests.
3. **Database:** MongoDB stores application data.
4. **Real-time communication:** Socket.IO enables chat sessions.
5. **Video communication:** WebRTC supports peer-to-peer video calls.
6. **Chatbot:** Offers quick guidance through a floating interface.

## 🎯 Project Objective

The goal of this project is to improve the convenience and accessibility of healthcare services by simplifying the process of connecting patients with doctors.

By integrating doctor discovery, appointment booking, real-time messaging, and video consultations, the platform demonstrates how web technologies can support remote healthcare interactions.
